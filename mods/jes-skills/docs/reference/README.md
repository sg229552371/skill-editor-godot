# reference/ —— 只读参考区（人类投放，AI 只读）

本目录存放**外部来源文档**，用于让执行 AI 在项目内就能读到完整依据，避免引用项目外的绝对路径。

## 投放规则（人类执行）

1. 把需要参考的外部文档**复制**（不是移动）到本目录，保留原文件名。
2. 复制后在《信息来源与真源清单.md》的「三、外部来源登记表」里补一行：文件名 / 来源 / 投放日期 / 用途。
3. 若文档只在设计阶段有效、不参与施工，请在文件名前加 `design_`；若参与施工，加 `spec_`。

## 使用规则（AI 执行）

- 本目录**只读**：AI 不得修改、不得在里面新建文件（本 README 除外）。
- 本目录**不是真源**：与《施工规格》《踩坑与决策台账》冲突时，一律以那两份为准。
- 本目录里的内容**不可作为施工依据直接执行**：需要落地时，先把结论写进《施工规格》对应章节，再按规格施工。
- 文件缺失时：**不要去找**，直接向人类说明「本次任务需要 X 文档，请投放至 docs/reference/」并暂停该部分工作。
