## 0. 参数集推导规则（每格参数 = 三条轴的键并集）

| 轴 | 取值 | 参数键（◇ = 未实现规划键） |

| 投送 `FLY` | 飞行物 | `speed` `lifetime` `pierce` `count_base` `spread_deg` `fork_count` `chain_count` `motion` `orbit_radius`（全 ✅，v1.5 D-36；`motion` ∈ {`linear`, `orbit`}，弹速唯一真源仍是 `speed`，orbit 弹不吃连锁/分裂）＋ 弹体 `radius` |
| 投送 `INST` | 瞬时点发 | 无投送键 |
| 投送 `CHAN` | 引导 | `max_channel_time` `tick_interval` |
| 投送 `DASH` | 位移 | `distance` `speed` |
| 投送 `SELF` | 自身 | 无投送键（增益时长 `duration` 由 `bhv_buff_self` ✅ 实现，属行为键） |
| 投送 `SUMN` | 召唤 | `max_count` `lifetime` |
| 形状 `PT` | 点 | 无（`FLY` 下 `radius` = 弹体半径） |
| 形状 `CIRC` | 圆 | `radius` |
| 形状 `RING` | 环 | `radius` `inner_radius`（D-31 ✅，默认 0 = 实心圆） |
| 形状 `SEC` | 扇 | `arc_deg` `range` |
| 形状 `LINE` | 线 | `range`（✅ 承载）＋ `length`✅ `width`✅（批次 A 实装，D-43） |
| 形状 `MULTI` | 多点 | `point_count`✅ `point_spacing`✅ `radius`（批次 A 实装，D-43；`FLY` 下散射仍由 `count_base`+`spread_deg` 表达） |
| 时序 `S1` | 单段 | 无 |
| 时序 `TICK` | 多段 | `tick_interval` `hit_count` |
| 时序 `DLY` | 延迟 | `delay` |
| 时序 `ZONE` | 持续区域 | `zone_duration`◇（可暂由多段模拟） |

> 每格基石参数集 = 该格「投送键 ∪ 形状键 ∪ 时序键」。施放层八项（耗蓝/冷却/前摇/充能/等级曲线等）是每格通用的第二层，不在本表重复。
> 别名须知：数据文件里发数一律写 `count_base`（`projectile_count` 是装配层自动处理的别名，P-06）。
