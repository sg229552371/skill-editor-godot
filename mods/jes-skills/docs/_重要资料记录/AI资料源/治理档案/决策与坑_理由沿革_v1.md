## 二、技术坑的根因（P-01 ~ P-23）

| 编号 | 根因 |
|---|---|
| **P-01** | `CanvasLayer` 属于 Node 分支，**不是 CanvasItem**，没有 `_draw()` / `queue_redraw()` |
| **P-02** | `_exec_projectile` 先设 `global_position`，随后 `setup()` 内部 `position = Vector2.ZERO` 把它抹掉 |
| **P-03** | `HitboxComponent.strike(hurtbox, rng, defender)` 的第三参不可省；不传会退回用 hurtbox 当 defender，而 hurtbox 没有 `.stats` |
| **P-04** | 出生点与施法者身体重叠，命中判定把自己算进目标 |
| **P-05** | 探针脚本弱类型变量用 `:=` 无法推断类型 → Parse Error → 场景永不 `quit()` |
| **P-06** | key 与行为层实际 `params.get()` 的键不一致；或误用内部规范化键 |
| **P-07** | 旧显示只有一个几乎不可见的 `·` |
| **P-08** | 全局脚本类缓存在 `.godot/`，只有编辑器导入时刷新，纯 headless 运行不会更新 |
| **P-09** | 池原本只服务「一个 Node 一个槽」，槽位不需要知道自己在哪个数组里；改成 SoA 后必须知道 |
| **P-10** | 假目标与假 hurtbox **互相引用**（`hurtbox.owner = target`），RefCounted 不回收引用环 |
| **P-11** | `SandboxEntity._init` 里 `new()` 了 `HurtboxComponent` 却**从未 `add_child`**，注释写了「在 _init 挂树」但代码没挂 |
| **P-12** | GUT 的命名是 `assert_gte` / `assert_lte` |
| **P-13** | ① 总线是**纯契约类**，信号只在声明处出现（emit 在 sandbox、connect 在 TriggerManager），而该警告只看「声明它的类自己用没用」；② `ProjectilePool._init(capacity)` 与 `func capacity()` 同名 |
| **P-14** | ① `ProjectileField.tick(dt, hash, ...)` —— `hash()` 是 GDScript 内置全局函数；② `sandbox_lab.gd` 的 `var scale` 在 Control 子类里撞了 `Control.scale` |
| **P-15** | `_build_skills()` 原来 `for i: _bind_skill_slot(i, skills[i])`，依赖工厂返回顺序（冰矛在 0）。换成 `GemRegistry.skills()` 后按 id 字母序 → 槽 0 变成 `berserk`（火/近战），`support_cold_focus`（require cold）被 G7 正确拒绝，整组连坐 |
| **P-16** | `StringName` 的默认比较不是字符串序 |
| **P-17** | `.tres` 是**进程级共享 Resource**：`load()` 返回同一个实例，测试里 `load(PATH).parts[0].behavior_params[...] = 3` 改的是全局，污染同进程后续所有测试 |
| **P-18** | `multiplier_of()` 与 `aggregate()` 复用同一个 `_sum_cache[stat]` 字典，`(stat, op)` 的键互相覆盖，把"求和值"当成"连乘中间值" |
| **P-19** | `bench_projectiles._refill()` 每帧 `DamagePacket.new()`，而子弹寿命 3 秒 → 稳态自然积压 180 个。这是**压测脚手架自身**的分配，被算进了被测代码 |
| **P-20** | 给 `tick()` 传了 `grid = null`，退化成 O(m×n) 暴力全扫：逻辑层占 **23.2 ms**，渲染只占 **0.96 ms**。误把逻辑成本算到渲染头上 |
| **P-21** | dummy 渲染器不提交任何绘制，也不保存实例数据 |
| **P-22** | ① 注释写的是设计意图，不是代码事实；② `TriggerData.linked_slot_index` 的语义（**目标槽**，不是触发源槽）没在字段处写明；③ 门禁句「8 个技能位全可用」被"槽里绑了东西"糊过去，没验"玩家/触发器真能用" |
| **P-23** | 内容数量断言写死了 |
