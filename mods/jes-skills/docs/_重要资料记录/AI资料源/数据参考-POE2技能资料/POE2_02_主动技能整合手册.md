# 《流放之路2》主动技能全量收集清单

> **数据来源与可信度（请先看这段）**
> 1. **名单与标签**为实抓自粉丝站 [POE2 Skills](https://poe2skills.com/skill)（自述 All 439 PoE2 Skill Gems）与 [PoE2 Vault](https://www.poe2vault.com/skills)（自述 369 active / 527 support，全站 896 条），交叉核对后收录。
> 2. **版本基准 0.5.0「远古归来（Ancients）」**（[更新说明](https://www.bilibili.com/opus/1205056429044531209)）。PoE2 处于抢先体验，每版都改，名单存在 0.5.x 热更差异。
> 3. **标签做了归一简化**：站点写的是 `Area`、`AoE`、`Chaining` 这类简写，**不含**官方 GGPK 的 `MeleeSingleTarget`、`ConsumesCharges`、`SkillConsumesPowerChargesOnUse`、`Multicastable`、`Cascadable`、`Unleashable`、`UsableWhileMoving` 等细粒度机制标签。要抓完整原始串需逐技能页去 [poe2db.tw](https://poe2db.tw/cn/)，本轮未做。
> 4. **魔力/冷却全部标「待提取」**：未逐页抓取数值（400+ 页面代价过高）。
> 5. 已剔除开发残留项（Playtest Attack / Slam / Spell、Removed Skill）。
> 6. 本表为纯收集，**不含任何系统设计推演**。
