## 三、验证习惯

- 改沙盒表现 → 用 windowed 探针截图（`get_viewport().get_texture().get_image().save_png()`），headless 看不到画面。
- 改装配/数值 → 至少跑 `test_s_sandbox_smoke.gd` + `test_s_support_pool.gd`，提交前跑全量 `-gdir=res://mods/jes-skills/tests -ginclude_subdirs`。
- 新增辅助石 → 先问「改了几个 `.gd`」，答案必须是 0；改了就说明把策略写进代码了。
- 新增属性 → 同样问「改了几个 `.gd`」，答案必须是 1（只动 `util/stat_registry.gd` 的 `DEFS`）。
- 改了 stats / 装配 / 缓存 → 必跑 `test_stats_dirty_cache.gd` + `test_m3_assembly_cache.gd`；这两处出错的表现是"数值差一点点"，肉眼看沙盒看不出来。
- 跑渲染压测 → **不能用 headless**：`godot --path . --script res://mods/jes-skills/tests/perf/bench_render.gd`，先确认 `DisplayServer.get_name() != "headless"`，否则读数作废。
