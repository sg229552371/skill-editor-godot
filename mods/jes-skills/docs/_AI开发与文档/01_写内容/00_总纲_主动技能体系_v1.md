## 0. 三十秒总览

主动技能体系 = **行为名称 → 基石 → 主动技能** 三层，外加标签体系与玩法路线：

```
行为名称 = 投送方式 × 判定形状 × 结算时序 × 辅助类别   ←「最小单元」，四轴冻结
基石     = 行为名称 + 关键参数（= 三条轴的参数并集）
主动技能 = 基石 + 施放参数（八项，见 §6）
标签     = 四轴确定性派生 + 元素 + 特性（一切皆标签，辅助宝石按标签区分）
```

本文回答四件事：行为名称全集总账（§3，矩阵展开见 02 号文档）、标签体系（§5）、施放层（§6）、玩法路线与待办（§8–§9）。

## 5. 标签体系（一切皆标签）

### 5.1 三类标签源

| 类 | 来源 | 例 |
|---|---|---|
| 初生标签 | 四轴各派生 1 个 + 元素标签（物理/火/冰/雷/混沌，来自伤害包） | 投送·形状·时序·辅助类别 + 元素。**元素不是轴**（否则格子数乘 5），此条写死 |
| 收敛标签 | 辅助宝石 `add_tags` 追加（多轮收敛，建议封顶 2 轮） | 装配后技能新增标签 |
| 特性标签 | 池抽项 / 触发器 / 条件门专属，白名单制 | 触发、条件 |

### 5.2 辅助宝石双向声明（引擎已实现，已核对）

- `require_tags` 需要标签：全部具备才兼容；
- `exclude_tags` 禁止标签：命中任一即拒绝；
- 判定顺序：**先查禁止，再查需要**；
- 独占组 `conflicts_with` 必须双向一致；
- **屏蔽只有一种机制 = 禁止标签**。三个挂点（技能级 `allowed_support_tags`、宝石级 `exclude_tags`、独占组 `conflicts_with`）都是它的变体。

### 5.3 部件级判定（定稿，2026-10-21）

双部件技能（如破阵翻滚 = 冲刺 + 增益）的两套初生标签若在技能级合并，辅助宝石会「判定通过但效果找不到归属」（案例：猎杀印记刷新冷却会连冲刺位移一起刷）。定稿：

- 标签**按部件派生**，兼容判定在**部件级**执行；
- 技能级标签只做展示聚合，不参与判定；
- 落地顺序：先按技能级实现（现状），部件级留接口，**第一批双部件辅助上线前切换**。

## 6. 施放层（主动技能 = 基石 + 施放参数八项）

| 小组 | 字段 | 回答的问题 |
|---|---|---|
| 成本参数 | 伤害、耗蓝、消耗类型、冷却、充能数+充能回复 | 这次施放付什么、多久能再放 |
| 节奏参数 | 前摇、等级曲线 | 多快出手、怎么成长 |
| 装配参数 | 部件绑定、允许辅助标签 | 基石怎么挂、辅助怎么配 |

**每秒伤害是导出列**（给人看平衡用），不在施放参数内。

数值护栏沿用手册 §4.2 区间；两条自检判据：单位化耗资 = 耗蓝 ÷ 冷却（或前摇），DPS 极差 > 2.5 倍即超模。

## 7. 玩法路线：池抽取三层（已验证方向，参数待拍板）

三段式 = 杀戮尖塔（固定骨架+随机池）→ Path of Achra（开局即见效）→ Noita 收敛版（全随机+锚点）：

| 阶段 | 玩家做什么 | 制作人做什么 |
|---|---|---|
| 初期 | 用完整固定技能学辅助宝石 × 遗物 × 技能互动 | 手写 N 个完整技能 + 教学关 |
| 中期 | 固定基石 + 对应池**三选一 + 可跳过**抽取 | 每基石池表 ≥8 项含 1 稀有 + 保底 |
| 中后期 | 章节主题加权随机抽基石 + **锁定 1 个** | 章节权重表 + 原型锚点校验 |

三修正：抽取必须三选一（「永远会选的选项不是决策」）；每个池项必须独立改变手感（禁止凑五件才好玩）；全随机必须收敛（章节加权 + 锁定），防构筑身份稀释。

首发规模建议：8 完整技能 / 4 基石 × 8 池项 / 2 章节加权随机。可选增量：重抽资源、组合发现图鉴。
