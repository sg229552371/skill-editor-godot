# 开工提示词（直接复制给执行 AI）

> 用法：把本文件与《施工规格_Godot技能系统_AI执行版_v1.0.md》《流放之路风格·高自由度技能系统规格.md》一起给执行 AI。下面的代码块是给它的第一句话。

```text
你的任务：在 Godot 4.7.x + GDScript 中，按《施工规格_Godot技能系统_AI执行版_v1.0.md》实现一套数据驱动的技能系统。
配套的《流放之路风格·高自由度技能系统规格.md》是设计意图，本施工规格是执行约束；两者冲突时以施工规格为准，
但需先向我指出冲突点，不要自行选择。

工作方式：
1. 先读施工规格 §0–§2，然后用你自己的话复述：七步管线顺序、辅助石三元组、四个必须自研的模块。复述通过再动手。
2. 严格按 §11 的 M0→M8 顺序推进。每个里程碑结束时，输出：改了哪些文件、测试通过数/失败数、门禁是否达标。
   门禁不达标就停下汇报，不要"先做后面的"。
3. 每个里程碑必须先写测试（§12 的 G1–G10 已给出期望数值），再写实现。
4. 遇到规格未覆盖的设计抉择，停下来问我，不要发明规则。

绝对禁止：
- 运行时代码里出现任何具体宝石 id 或写死的数值（全部进 .tres）
- INCREASED 逐条相乘（必须求和后一次乘）
- 让点燃/中毒吃 hit damage 词缀（通道必须隔离）
- 每个投射物挂 Area2D、每个 DoT 挂 Timer、热路径 instantiate/free
- 同时存在两条减伤管线
- 复制 Simplereally/the-exile-engine-v2 的任何代码（该仓库无许可证）
- 使用 Path of Exile 的技能名与数值表

第一个交付物：M0 完成后，给我一份 5 行以内的报告 + `godot --headless` 跑测试的完整输出。
```

---

## 给人类的三条使用建议

1. **一次只给一个里程碑**。M0–M1 通过后再给 M2，否则 AI 会为了"看起来完整"而跨越门禁。
2. **每次 review 只看两件事**：① 有没有出现写死的宝石 id / 数值；② 新增一个辅助石需要改几个 `.gd`（应为 0）。这两条能挡掉 80% 的架构腐化。
3. **G6 和 G9 是最容易被糊弄的两条**（卸下还原、通道隔离）。要求 AI 贴出断言代码原文，不要只看"测试通过"。
