UI 出 bug 先想"core 是不是对的"，core 出 bug 先跑测试再改。

## 二、核心规则（不得违反）

1. **双背包**：A = 武器背包（5 行×7 列，**生效**），B = 临时仓库（5 行×6 列，**不生效**）。
   只有 A 包道具的 stats 计入角色属性（`core.stats`）。
2. **左上角锚点**（制作人 2026-10-22 裁定）：拖拽时道具左上角跟手，
   目标格 = 道具左上角所在格（内缩 2px 防边缘抖动）。不得改回"中心定锚"。
3. **落子三结果**（core.drop 互斥返回）：
   - `placed`：空位直落
   - `swapped`：落点被单个其他道具占住 → 互换锚点（对方放不下则双方弹回）
   - `bounced`：越界 / 压住 ≥2 个道具 → 弹回原位
4. **拖拽高亮**：绿 = 可放或可互换（压 ≤1 个），红 = 不可放；越界格不画。
5. **竖屏 390×844**：几何常量全部对齐 HTML 原型
   （包体 A(8,112) / B(8,528)，宽 374 高 271，网格在包体内 (8,27)，CELL=44 GAP=4）。

## 四、如何新增道具（含任意形状，v2 异形支持）

**只改 `ui/bag_defs.gd`，其他文件一律不动**——渲染和逻辑是数据驱动的。

### 矩形道具（w×h 满占）

```gdscript
{"id": "w10", "name": "巨盾", "icon": "shield", "rarity": "epic", "w": 2, "h": 3,
    "stats": {"hp": 50, "move": -5}, "desc": "又大又重。"},
```

### 异形道具（0/1 网格，v2 起支持）

```gdscript
{"id": "w09", "name": "缺角铁牌", "icon": "brick", "rarity": "epic", "w": 2, "h": 2,
    "shape": ["11", "10"],
    "stats": {"hp": 30}, "desc": "缺了一角，但很能扛。"},
```

**形状格式规范**（业界标准 polyomino 表示，查证来源：Unity 论坛 / Opsive Ultimate Inventory System / Tetris 类背包游戏）：
- `shape` = 字符串数组，每行**等长**，`1` = 占格，`0` = 挖空
- 无 `shape` 字段 = 满矩形（按 w×h 展开），旧数据零改动兼容
- `w`/`h` 始终是**包围盒**尺寸（决定渲染节点大小和 TIPS 显示）
- 锚点固定为包围盒左上角 (0,0)，与左上角拖拽锚点裁定一致；**建议 (0,0) 格写 1**
- 行为：占格登记 / 碰撞 / 互换 / 弹回 / 拖拽高亮 / 渲染全部逐格生效，挖空处不画不高亮

**通用注意事项**：
- `id` 不要重复；`rarity` 只能是 common/rare/epic/legend
- `icon` 需在 `bag_ui.gd` 的 `ICON_EMOJI` 登记 emoji 映射（没有则显示 ❓）
- `stats` 键：atk/spd/crit/move/hp
- 可选在 `LAYOUT` 加 `{"item": "wXX", "bag": "A", "x": 0, "y": 3}`（别和已有道具重叠）

**告诉 AI 的模板**（直接贴给 AI 即可）：

```
新增道具：名称=巨盾，图标=🛡️，稀有度=史诗，占格=2×3，
属性=生命+50 / 移速-5，描述=……，初始位置=A包(0,2)
```

异形再加一行形状（用 / 分行或直接多行贴 0/1 网格）：

```
形状=1111/0001/0001/1111
```

## 五、验证流程（改完必跑）

1. 逻辑/UI 冒烟（headless，全绿才算完）：
   `Godot --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://mods/jes-bagrogue-inventory/tests -ginclude_subdirs -gexit`
2. UI 冒烟脚本方式：
   `Godot --headless --path . --script res://mods/jes-bagrogue-inventory/tests/test_bag_ui.gd`
3. 真实渲染检查（不能 headless，dummy 渲染器不提交绘制）：
   `Godot --path . --script res://mods/jes-bagrogue-inventory/tests/capture_bag_ui.gd`
   → 输出 PNG 到 `tests/_capture/`，人工过目
4. 手动：编辑器打开 `bag_ui.tscn` → F6（场景自带 StageFit 竖屏声明）

注意：headless 冒烟**测不出信号接线错误**（gui_input 参数顺序曾漏网），
凡改了信号连接/交互代码，必须做第 3 或第 4 步实跑。

## 六、已知边界与后续

- 道具图标目前用 emoji（SystemFont 渲染），`icon` 字段已预留换纹理
- 异形道具的鼠标判定仍是包围盒（点挖空处也会抓起道具），视觉上挖空不画；后续需要精确判定再改
- 旋转（90°）未实现；业界做法是按 shape 矩阵转置生成新 shape，需要时再加
- HP 条当前恒为满（hp 上限未独立建模），纯展示
- `capture_bag_ui.gd` 里的拖拽是模拟字典注入，真拖拽以手动 F6 为准
- HTML 原型（sandbox/）不再同步，Godot 版为唯一真源；后续新布局先在 Godot 版验证
