## cast 适配器的语义（本卡唯一实现）

数据来自模板 `cast` 段（字段名以 `data/params_meta.json` 与 `cfg_schema.gd` 的落点为准，**不许自造字段**）。
已知字段：`windup_ticks`、`shot_ticks`、`shot_count`、`cooldown_seconds`。读不到就显式失败，不许给默认值（D-21）。

1. **validate 严格拒绝**：`windup_ticks` / `shot_ticks[i]` / `shot_count` 必须是 `int` 且 `>= 0`
   （JSON 素材里是 float，**只有作者填进 CFG 的才用严格 `is int`**，坑 9）；
   `shot_ticks` 必须严格递增且 `>= windup_ticks`；`shot_count` 与 `shot_ticks.size()` 不一致 → 失败并点名两者；
   `cooldown_seconds` 必须 `> 0`，转 tick 用 `project_config.json` 的 `tick_rate`，不许写死 60。
2. **前摇**：`begin` 记录 `start_tick`；`0 <= t < windup` 期间不产生任何 spawn；前摇期间收到 `interrupt`
   → 状态转 `cancelled`，此后 `advance` 恒产出空 emissions 且不再 spawn。
3. **出手**：仅当 `current_tick - start_tick == shot_ticks[i]` 时产出该发 spawn，每发**只出一次**（重入同 tick 不得重复）。
   `shot_id` 必须由调用方提供，**不许自造**（派单 T-050 的规矩：shot_id 是真实身份）。
4. **冷却**：cast 结束后 `cooldown_seconds * tick_rate` 个 tick 内，`begin` 必须失败并点名剩余 tick 数。
   冷却是**公共**的：同一适配器实例上，前一个 cast 的冷却未结束，任何新 `begin` 都失败。
5. **到期**：`shot_ticks` 全部出完后状态转 `done`，`advance` 空转，不再产出。

## 测试要求

`test_host_registry.gd`（≥8 用例）：
- 注册后 `has_adapter` 为真、`sections()` 次序按 `SECTIONS`；
- 重复注册失败；未知 section 失败；null / 缺方法适配器失败（缺 `validate`、缺 `begin`、缺 `advance` 各一例）；

`test_host_cast.gd`（≥10 用例，覆盖 ED-17-09/10/12/19）：
- 前摇期无 spawn（逐 tick 断言 spawn 总数不变，先建立 `shot_ticks` 非空基线，坑 13）；
- `shot_ticks=[2]` 只在第 2 tick 出一次（前后 tick 都断言为 0）；
- `shot_ticks=[3,5]` 恰好两发且 tick 精确（不是「至少一发」）；
- 打断后不再出手，且状态为 `cancelled`；

- 非整数 / 负数 / 非递增 / `shot_ticks < windup` 各自失败，path 精确指到字段；
- 每发只出一次（同 tick 重复 advance 不重复 spawn）。
