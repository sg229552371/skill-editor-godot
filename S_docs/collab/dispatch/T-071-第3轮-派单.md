## 要验的契约（第 1 轮派单原文，逐字不变）

适配器 duck-typing 三方法：

```gdscript
func validate(request: Dictionary, ctx: Dictionary) -> Dictionary
func begin(request: Dictionary, ctx: Dictionary) -> Dictionary
func advance(state: Dictionary, tick: int, ctx: Dictionary) -> Dictionary
```

`emissions` 只认四键：`spawn` / `attach` / `events` / `records`。

注册表：`register` 重复注册必须失败、未知 section 必须失败、
无适配器时错误必须含 `Host adapter` 与 section 名、`sections()` 按 `SECTIONS` 次序。

cast 语义：`shot_count >= 1`（素材 `params_meta.json:222-226` 的 `minimum=1`，第 2 轮已裁定）；
`shot_ticks` 严格递增且 `>= windup_ticks`；`windup_ticks` 允许 0；
`cooldown_seconds > 0` 且用 `project_config.json` 的 `tick_rate` 换算，**不许写死 60**；
前摇期不 spawn；每发只出一次；打断后不再出手；冷却内 `begin` 失败并点名剩余 tick。
