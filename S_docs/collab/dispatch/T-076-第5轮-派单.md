### 2. 补正向验收（`tests/test_ed17_capability.gd`）

**非空对照是硬要求**（坑 13）：

| 验收 | 断言 |
|---|---|
| 冷却期内**槽 A** 操作被拒 | 具体拒绝原因原文，不许只断言 `ok == false` |
| 冷却期内**槽 B**（**不同的另一个槽**）操作**同样被拒** | 同上 —— 证明冷却是**装配级**不是槽级 |
| 冷却结束后**同一操作成功** | 成功后的实际状态快照 |
| **非空对照** | 冷却期内被拒 vs 冷却后成功，**同一操作两种结果必须实际观测到**，否则"被拒"可能是恒真 |

**不许 pending / skip / 只断言 `ok == true`**。

### 3. 真源三条口径（逐字核对后再写）

- `:2663`：水晶/遗物有效装配可卸下或替换；替换为空也是替换；在 tick 开始、任何出手前整批原子应用；
  **公共冷却期拒绝所有装配槽操作**。
- `:2667`：装配公共冷却、技能冷却、被动内置冷却**必须分别命名、分别显示**；一个结束不代表另外两项结束。
- `:6890`：替换在 tick 开始、该 tick 任何出手之前统一应用，整批原子发布，中间态不可见。

**铁律**：`HostCast._cooldown_until` 仍只表示**技能冷却**，**绝不可**当作装配公共冷却使用或复用。
