## 冻结契约（帧模型，审核方定）
```gdscript
# 单个可绘制项：
# {"kind": "shape" | "trail" | "damage_number",
#  "pos": Vector2 (或 {x,y}), "size": Vector2 / float,
#  "color": Color / "#rrggbb", "text": String,   # damage_number 用 text
#  "ttl": int}                                   # 剩余存活 tick，<=0 不画
# API：
# render_frame(items: Array) -> Dictionary   # {ok, drawn: int, error}
# get_last_frame_items() -> Array            # 供无帧 headless 断言（渲染后快照）
# configure(metadata: Dictionary) -> Dictionary  # 形状名→绘制方式、伤害数字格式来自注入
```
- 目标**不是美术**，是"够验证搭积木效果"：形状可见、拖尾可见、伤害数字可见。

## 验收硬标准
1. 三种 kind 各至少一条用例：`drawn` 计数正确、`get_last_frame_items()` 能逐项回读（headless 无帧也能断言）。
2. **`ttl <= 0` 不绘制**；`ttl` 递减后同一批项逐渐消失（至少跑 3 帧验证）。
3. **非法帧**：kind 未登记 / pos 非数值 / items 非 Array → `ok:false` + **点名**是哪一项哪个字段
   （不许整批静默丢弃、也不许只报"非法输入"）。
4. **不读 CFG、不算伤害**：代码里不出现对 `skill_core` 业务模块的调用（可 preload 但不调用业务逻辑）；
   `text` 由上游给，渲染器只负责画。
5. 形状名/伤害数字格式来自注入 metadata；换注入后输出随之变化（证明表驱动）。
6. 入参数组不被修改（深拷贝比对）；`get_last_frame_items()` 返回副本，外部修改不影响渲染器状态。
7. 未 configure → 显式失败（不静默按空配置画）。
