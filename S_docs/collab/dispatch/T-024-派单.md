## 一、任务

产出 `res://addons/skill_editor/ui/diagnostic_panel.gd`（+ 需要的 `.tscn`）：把校验结果**呈现给两种人**。

WBS 验收三条（真源口径）：
1. **策划视图 / 程序视图看的是同一份诊断**（不是两套数据、两种过滤）。
2. **点击诊断 → 展开折叠区并定位到字段**。
3. **字段位于积木默认值时，先提示「错误来自默认卡」，不自动复制到覆盖区**。

第 3 条是本卡的灵魂，别做反了：
策划在表单里改的是**覆盖区**（`params`），但很多错误其实出在**积木卡的 `default_cfg`** 里。
面板必须**先说清「这个错来自默认卡」**，并且**绝不**自动把默认值复制进覆盖区来「消掉」报错 ——
那会污染作者的覆盖表、掩盖真正的缺陷来源。

## 四、验收硬标准

1. **双视图同源**：策划视图与程序视图消费**同一份已排序诊断数组**；
   断言两者条目数一致、`rule_id` 序列一致（顺序也一样）。差异只允许在**呈现字段**：
   策划视图给 `hint`（人话）/ 程序视图给 `rule_id + code + path + actual/expected`。
2. **点击定位**：点一条诊断 → 折叠区展开，并暴露「要定位的字段路径」；
   断言面板对外给出了 `path`（例如回调/信号携带 `bricks[2].author_params`），
   且**重复点同一条不会重复展开/重复发信号**。
3. **来自默认卡的提示（核心）**：
   - 诊断 `path` 命中 `bricks[i].default_cfg.*` 或以积木默认值为来源时，面板**必须**显示「错误来自默认卡」类提示；
   - **必须断言面板在展示后没有往覆盖区写任何东西**（传入的覆盖表 `duplicate(true)` 前后 `assert_eq`，
     以及 JSON 序列化逐字节相同 —— 照 T-023 ④ 的写法）；
   - 明确**不提供**「一键复制到覆盖区」的静默行为；若要做「复制到覆盖区」必须是**独立显式操作**且本卡不实现。
4. **严重度分组呈现**：按 `severity_order` 分组（阻止保存→警告→提示），组内保持排序器给的顺序；
   **不许按自己的规则重排**。断言：注入乱序诊断（如 HINT、BLOCK、WARN 交错）→ 面板输出顺序等于排序器输出顺序。
5. **空诊断**：0 条时给出「无诊断」态，不抛错、不留残留条目（先展示后清空也要回到空态）。
6. **不写回 / 不改诊断对象**：面板不得修改注入的诊断对象（断言注入前后诊断数组深拷贝一致）；
   诊断对象不许共享可变引用。
7. **素材/注入缺失显式失败**：注入的不是 Array、或元素不是 `Diagnostic`，面板显式报错（D-21），不许静默空跑。
8. **表驱动 + 不硬编码**：严重度分组、视图字段映射全部来自注入/素材；
   **禁止**在代码里写死具体 `rule_id`、字段名、严重度数值。

## 五、坑位清单（前 15 张卡踩出来的，逐条避开）

1. `:=` 遇 Variant 推断失败 → 整脚本编译失败。
2. `dict.get(k, {})` 可变默认值掩缺键 → 默认 `null` + 回写（D-20）。
3. 禁在 `_init()` 里解析 md/yaml/RegEx。
4. 函数头丢失 → `Function X() not found in base self` 第一条才是真定位点。
5. **Variant 跨类型比较抛运行时错误** → GUT 记 Unexpected Errors；先转 `String`。
6. 点语法写新键生成 **StringName** 键 → 新键一律 `dict["k"] = v`。
7. `Diagnostic` 只有 `SEV_BLOCK/WARN/HINT`。
8. 显式类型变量赋 null 抛错 → 容器取值先 `Variant` 再 `is` 判定。
9. 素材 JSON 数字恒 float（`is int or is float`）。
10. 素材路径含 `[i]` 与作者键是两套判据。
11. 素材 `_` 前缀键是注释，跳过。
12. 测试里别调 GUT 不存在的方法（`fail()`）→ 0 用例假绿；用 `assert_true(false, "…")`。
13. **恒真断言**：先跑基线，断言「相对基线新增」；写每条断言前问基线下是不是本来就满足。
14. 素材侧严格 `is int` 会把 `1.0` 判非法（T-016 真炸过）。
15. **新增 `class_name` 不能当类型名用** → preload 常量标注。
16. UI 测试跑在 **headless**：不依赖 `EditorInterface`、真实对话框、需要多帧迭代的逻辑。
