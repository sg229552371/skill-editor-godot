## 契约（T-050 在并行落地，签名已冻结）

```gdscript
# preview_runner.gd（已冻结）
func start(cfg: Variant, options: Dictionary) -> Dictionary
func advance_ticks(count: int = 1) -> Dictionary
func snapshot_state() -> Dictionary     # 返回的是快照，改它不影响 runner
func stop() -> Dictionary
```

本卡**不启动 runner**，只做「把一次快照渲染成三栏」。入口：

```gdscript
func configure(view_fields: Dictionary, limits: Dictionary) -> Dictionary   # {ok, error}
func ingest(snapshot: Dictionary) -> Dictionary                            # {ok, error, entries}
func get_entries(column: String) -> Array                                  # "events" / "settle" / "debug"
func clear() -> void
```

`view_fields` 决定每栏展示哪些字段（**列/字段名必须来自注入素材，不许写死**）。

## 验收硬标准

1. **三栏都有独立内容**：一条快照同时产生 events / settle / debug 三类条目，
   三栏 `get_entries()` 各自非空且**内容互不相同**（逐项比对，不是只看长度）。
2. **正式与调试数据严格分离（D-24）**：
   - `settle` 栏只吃**结算记录**（`hit` / `hit_settled` / `evaded_all` 这些**已登记**的记录种类，
     具体枚举去 `skill_core/runtime/settle.gd` 与 `data/enums` 里读，**不许猜**）；
   - `debug` 栏只吃 `debug_record` 一类**调试专用**条目；
   - **用例必须证明**：把同一批条目混着喂进去，`settle` 栏**不含任何** `debug_*` 条目，`debug` 栏**不含任何**结算条目
     （互相不串栏）。**这是本卡最重要的一条，不许用「非空」糊过去。**
3. **`_` 前缀键是注释，不是条目**：快照里含 `_note` 之类的键时，三栏都**不得**把它当条目渲染（坑 11）。
4. **未知记录种类显式失败**：出现未登记的记录种类 → `ingest()` 返回 `ok=false` 且错误**点名该种类**，
   不许静默丢弃（D-21 缺素材 → 显式失败）。
5. **不改入参**：`ingest()` 前后对入参 snapshot 深拷贝 + `JSON.stringify` 比对一致；
   返回的 entries 改一下不影响面板内部（快照脱离）。
6. **字段名跟着素材变**：换 `view_fields` 后，条目里呈现的字段集合随之变化（证明不是写死列）。

## 实现约束

- `String(x)` 不是万能转换（`String(Color)`/`String(null)` 运行期炸）→ 用 `str()`（坑 16）。
- 不要用 `class_name` 当类型名 → `const X = preload(...)`（坑 15）。
- 素材里的数字恒 float，需要 int 时显式 `int()`（坑 9）。
- 排序/分组**不要自己写**：需要排序就注入 `validator`/`sorter` 已有实现，面板不重排（与 T-024 同口径）。
