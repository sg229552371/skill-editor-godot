## 一、本卡任务

### 1. 构造一张真实设计卡 CFG（不是夹具）

- 内容要求：能表达完整技能的卡 —— 至少含 `bricks`、`params`（含暴露字段）、`presentation`（**不启用 `anim` 段**，见 §四.9）、
  `meta`（含 skill_id / version）、`runtime_hints`。**七键齐全、schema-clean**。
- **禁止**放未登记 `params` 键（**U-32**：schema 层 V-019 会拒，走 `create_sim` 必红）。
- **落盘纪律**：CFG 一律落 `user://t078/`，**禁止在 `res://` 下新建 CFG**
  （会连带产生 `.import` / `.uid` 未跟踪文件，污染工作树）。

### 2. 逐步跑通 20.1.1 → 20.1.7，每步留**运行凭据**

凭据 = **实际输出原文**（不是「应该有」「符合预期」这类描述）。每步至少留：

| 步骤 | 凭据内容 |
|---|---|
| 20.1.1 填卡 | 完整 CFG 原文 + 路径表（哪些路径被登记/暴露/锁定） |
| 20.1.2 即时校验 | 非法值输入的**实际诊断数组原文**（含 rule_id / path / severity）+ 修复后**同入口**复跑的诊断数组（旧诊断确实消失） |
| 20.1.3 整卡校验 | 六入口跑完的**诊断摘要**（分严重度计数）+ **依赖指纹**（实际计算出的值，不是描述）+ 断言**无阻止项** |
| 20.1.4 保存 | 落盘文件原文 + **重新加载后深比较**结果 + `meta.version` 实际值 + 规范化差异（有则列出，无则显式写「无差异」） |
| 20.1.5 预览 | 三栏（事件 / 结算 / 调试）**实际条目原文** + 固定初态/输入/种子的实际值 |
| 20.1.6 正式复现 | 正式入口（`save_cfg`→`load_cfg`→`create_sim`）与预览入口的**首差异检查实际输出**（T-077 已有对照，本卡要在这张真实卡上复现一次） |
| 20.1.7 重跑 | **两次**同输入同种子的完整 trace + **比较报告**（逐项相等 / 首差异为空，附实际输出） |

**20.1.10 证据绑定**：所有凭据必须绑定 **CFG 内容指纹** + **素材/schema 版本**；
存档时写清「本凭据对应哪个指纹」。**旧证据不得贴到新版本上**。

### 3. 固化成集成测试 `tests/test_m6_end_to_end.gd`（新增）

把 §2 的链路做成**一个可进门禁的 GUT 测试**：同一张卡跑完 20.1.3→20.1.7，
断言每步的实际结果（**不许只断言 `ok == true`** —— 那等于没证明）。

最低验收：

1. 整卡校验**无阻止项**（severity 为 block 的诊断数 == 0，断言具体数字）。
2. 保存→重载**深比较相等**；`meta.version` 实际取值断言（不许只断言非空）。
3. 预览三栏**各自非空**（事件/结算/调试分别断言条数 > 0，对应 **20.1.9 非空要求**）。
4. 正式/预览双入口**首差异为空**（附实际输出）。
5. 重跑两次 trace **逐项相等**（首差异为空，附实际输出）。
6. **非空对照（坑 13）**：上面每条「相等 / 为空」断言，都要证明**破坏后确实能检出差异**
   —— 例如改一个参数后首差异**必须非空**，否则「首差异为空」可能是空集合恒真。
