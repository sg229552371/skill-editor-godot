## 这张卡要解决的一件事

**同输入同种子两次跑，逐 tick 一致；不一致时能指出「第一次出现差异的是第几个 tick、哪条轨迹、哪个字段」。**
真源口径：逻辑 RNG 与表现 RNG 分离（D-09），逻辑轨迹不允许被表现侧污染。

## 契约（冻结，按此写；上游 T-050/T-052 在并行，不要等）

runner 已有（已冻结）：
```gdscript
func start(cfg: Variant, options: Dictionary) -> Dictionary   # options 含 seed / tick_rate 等，键名去 preview_runner.gd:61 读

func snapshot_state() -> Dictionary
func stop() -> Dictionary
```

本卡新增：
```gdscript
const RunDiff = preload("res://skill_core/runtime/run_diff.gd")

func configure(options: Dictionary = {}) -> Dictionary        # {ok, error}；options 可含轨迹字段白名单
func capture(runner: Variant, ticks: int) -> Dictionary        # {ok, error, trace}  trace: Array[tick -> Dictionary]
func compare(trace_a: Array, trace_b: Array) -> Dictionary     # {ok, equal, first_diff_index, path, left, right, error}
func diff_runs(runner: Variant, cfg: Dictionary, ticks: int) -> Dictionary  # 跑两次同参再比对
```

`trace` 每个元素必须带 `tick`（int，0 起）；`compare` 的 `first_diff_index` 是**下标**，
`path` 是**定位到具体字段的路径串**（例如 `trace[7].entities[2].position.x`），**不是**只说「不一致」。

## 验收硬标准

1. **两次一致**：同 CFG 同 seed，两次 `capture` 的 `trace` 逐 tick `JSON.stringify` 相等；
   `compare` 返回 `equal=true`、`first_diff_index=-1`、`path=""`。
2. **首差异可定位**：故意在第 7 tick 改一个叶子（用注入的 `post_tick_hook` 或在第二次跑时改 CFG，
   **不许改 runner 内部状态**）→ `equal=false`、`first_diff_index` **恰好等于**那个 tick 在 trace 里的下标
   （断言具体值，不是 `> 0`），且 `path` 非空并**包含该字段名**。
3. **首差异是「第一个」不是「任意一个」**：构造从第 5 tick 开始连续 3 个 tick 都不一样 →
   `first_diff_index` 必须指第 5 tick 那个（断言等于它，防「随便报一个」）。
4. **表现 RNG 不污染逻辑**（D-09）：两次跑，**第二次额外调用 `runner.presentation_random()` 若干次** →
   逻辑 `trace` 仍然完全一致（这条是本卡的核心，不许省）。
5. **不写回**：`capture`/`diff_runs` 前后对入参 cfg 深拷贝 + `JSON.stringify` 比对一致。
6. **显式失败**：①未 configure 调用 → `ok=false`；②`runner` 缺方法（传 `null` 或 `{}`）→ `ok=false` 且点名缺什么；
   ③`compare` 两个 trace 长度不等 → `ok=false` 且**报出两边长度**（不许静默按短的比）。
7. **trace 有界**：`ticks` 传 0 或负数 → 显式失败；传超大值（如 100000）→ 必须**按上限截断并报 `truncated=true`**，
   不许 OOM（上限从注入的 `limits.max_trace_ticks` 读，没注入就显式失败 —— **不写死数字**）。

## 实现约束

- `String(x)` 不是万能转换（`String(Color)`/`String(null)` 运行期炸）→ `str()`（坑 16）。
- `const` 常量名不得与原生类同名（`Shape`/`Body`/`Panel`…）→ 用 `ShapeProbe`/`BodyImpl` 这种（坑 17）。
- 不要 `class_name` 当类型名 → `preload`（坑 15）。
- 素材/JSON 数字恒 float（坑 9）；`_` 前缀键是注释（坑 11）。
- **浮点不要用 `==` 比**：轨迹里数值统一序列化成字符串再比（`JSON.stringify` 即可），避免 `0.1+0.2` 抖动导致假差异。
- 别调 GUT 不存在的方法（`fail()`）→ `assert_true(false, "T-053 ...")`（坑 12）。
