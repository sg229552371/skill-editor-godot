## 必须实现的行为
1. **修饰器列表编辑**：按注入的 modifier 定义渲染（目标路径、运算、数值、优先级、作用域），
   增删改只改本面板持有的 draft，**不写回传入 CFG**。
2. **六字段接口不暗加孤立字段**：暴露字段严格六字段，面板**不允许**出现第六字段之外的输入控件；
   若注入的 field 定义含未知键 → 显式失败并列出键名（不要静默忽略）。
3. **`tagged` 作用域必须显式标注为「作用域标签」**，不得渲染成"值"或"开关"（真源要求：标签不是可编辑值）。
4. **权限三档**：`relic` 修饰器只读展示、`author` 可编辑、`locked` 不可见/禁编辑（按 `item_permission_policy.json` 注入，不写死字符串）。
5. **U-22 未就位前的临时口径**：目前 core 无「按路径查询锁定/开放」façade，
   面板允许做**展示侧**匹配，但**必须** `// TODO(U-22)` 标注，且**不得**用该判断做任何保存/校验结论。

## 验收硬标准
1. 渲染条数 = 注入定义条数；顺序 = 注入顺序（换顺序后输出随之变化，证明不是写死）。
2. 六字段之外的控件数量 == 0（遍历子节点断言，别只检查"有六列"）。
3. 注入含未知字段键 → `ok:false` + 错误里**点名**该键（不是泛化"字段非法"）。
4. `tagged` 作用域渲染出的节点类型/文案可被断言为「标签」（如 `Label` 而非 `LineEdit`），且不可编辑。
5. 三档权限各一条用例：relic 只读（设置被拒）、author 可改（draft 变化）、locked 不出现。
6. draft 隔离：入参 CFG 深拷贝 + `JSON.stringify` 前后一致；外部改返回值不影响面板状态。
7. 未 configure / 缺素材 → 显式失败并显示错误（不是空白面板）。
8. 表驱动：无具体字段名/修饰器 ID 硬编码分支。
