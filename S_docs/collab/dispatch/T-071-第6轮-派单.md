## 允许的 7 类改动

1. **preload**：加 `HostRegistry`、`HostCast` 两个 const。
2. **成员**：`_hosts: RefCounted`、`_host_states: Dictionary`、`_host_requests: Dictionary`、`_host_contexts: Dictionary`。
3. **start() 注册**：在 metadata 检查之后 `_hosts = HostRegistry.new()`，
   `register("cast", HostCast.new())`，失败 → `_failure("hosts.cast", ...)`，并清空三个宿主字典。
4. **section 检查**（`start()` 里那五 section 的 `for`）：
   改成「无适配器 → 保留拒绝，文案含 `Host adapter` 与 section 名；有适配器 → `validate()` 失败原样返回 path/error，
   通过则 `begin()` 并把 state 存进 `_host_states`」。**其余四个 section 不注册，保持拒绝。**
5. **抽取 `_launch_root(launch: Dictionary) -> Dictionary`**：把 189–211 行循环体搬进去，
   返回 `{ok, admitted, id, error, path}`。**`_root_seq` 分配、`_budget.admit_root`、`_derive.register_root`、
   `Body.create`、`_build_entity`、`_facts` 的调用次序与参数一个都不许变**；`continue` 保留在调用方。
6. **`_consume_emissions(emissions) -> Dictionary`**：只认 `spawn`/`attach`/`events`/`records`，
   第五个键 → 失败并点名；`spawn` 交给 `_launch_root`，`events`/`records` 追加到既有流
   （用文件里**现有**的流成员名，不要新造）。
7. **host 推进**：新增 `_advance_hosts(tick: int) -> Dictionary`，逐宿主调 `advance("cast", state, tick, ctx)`
   并消费 emissions。`start()` 成功路径末尾调一次 `_advance_hosts(0)`（让 `shot_ticks=[0]` 即时出手）；
   `advance_ticks()` 每 tick 调一次。
