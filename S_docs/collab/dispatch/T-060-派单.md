   逐槽独立可编辑；槽列表与字段**从 `presentation_meta.json` 派生**，不写死七段名字符串分支
   （允许一个常量数组表达"七段"这个概念，但每段的叶子字段必须来自素材）。
2. **空段 = 未绑定资源**：`{}` 或缺失 → 面板显示「未绑定」，**不得**自动填任何默认资源、

## 验收硬标准
1. 七槽全部渲染（断言槽数量与槽名集合来自素材，换素材后随之变化 —— 证明不是写死）。
2. 空段：渲染出「未绑定」状态；**且** `get_value()` 回传的是空字典，不是被填充过的默认资源。
3. 每槽的叶子字段集合 == `presentation_meta.json` 中该段登记集合（逐槽比对，至少覆盖 3 个槽）。
4. `carrier` 下拉选项 == 素材枚举（逐项相等），非法值被拒并点名。
5. draft 隔离：入参 CFG 不变；外部改 `get_value()` 返回值不影响面板。
6. 缺素材/未 configure → 显式失败并显示错误，不静默空面板。
7. 表驱动：除"七段之概念"外，无具体字段名硬编码分支。
