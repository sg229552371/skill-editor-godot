## 已批准的 6 类改动（其余一律不许）

1. **成员**：新增 `_hosts`（注册表实例）、`_host_states`、`_host_requests`、`_host_contexts`。
2. **注册 cast**：`start()` 里 `_hosts = HostRegistry.new()`，`register("cast", HostCast.new())`，
   注册失败 → `_failure("hosts.cast", ...)`。**其余四个 section 不注册**，保持拒绝态。
3. **section 检查改派注册表**：五 section 循环里，`has_adapter(section)` 为真则
   `_hosts.validate(section, template[section], ctx)`，失败原样返回其 `path`/`error`；
   无适配器**保留原拒绝**，文案必须含 `Host adapter` 与 section 名。
   **注意：`carrier != CARRIER_INDEPENDENT` 那条检查本轮不许动**，保持"只要 independent"。
4. **抽取根启动**：把 `start()` 里创建根的那段逻辑抽成 `_launch_root(launch: Dictionary) -> Dictionary`，
   让 `start()` 循环与 emissions 消费共用。**抽取必须行为等价**：预算 `admit_root`、`_derive.register_root`、
   `Body.create`、实例 id 分配次序与参数一个都不许变。`continue` 语义原样保留。
5. **消费 emissions**：新增 `_consume_emissions(emissions: Dictionary) -> Dictionary`，只认
   `spawn` / `attach` / `events` / `records` 四键，出现第五键 → `_failure` 并点名该键。
   `spawn` 交给 `_launch_root`，`events`/`records` 追加到既有流。
6. **tick 0 与每 tick 消费**：`start()` 成功末尾消费一次 `advance(state, 0, ctx)` 的 emissions
   （使 `shot_ticks=[0]` 能即时出手）；`advance_ticks()` 每 tick 在**既有 tick 逻辑之后**消费一次。
