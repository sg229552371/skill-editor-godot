## 11.2 修复：Variant 跨类型比较抛运行时错误（坑 6）

```
SCRIPT ERROR: Invalid operands 'Array' and 'String' in operator '!='.
   at: ModifierRules._existing_targets (r_modifier.gd:235)
SCRIPT ERROR: Invalid operands 'Array' and 'String' in operator '=='.
   at: ModifierRules._numeric_modifier (r_modifier.gd:321)
```

**根因**：`test_v040` 把 `permission` 填成 `["mutate_number","add_behavior"]` / `"unknown"` / `null`，
引擎在 235 / 249 / 321 行直接拿它与字符串做 `!=` / `==`。GDScript 4 跨类型 Variant 比较**不中断脚本**，
但被 GUT 记为 `Unexpected Errors` → 整个用例红掉，且断言数只差 1（731/732），极难一眼看出。

**修复**：新增 `_permission_text(hit) -> String`（非 String 即返回 `""`），所有分档判定改吃它：

- `_permissions`（V-040）：仍是权限的类型/枚举关卡，数组 / 未知 / null 都在这里拦；
- `_item_permissions`（V-041）、`_existing_targets`（V-044）、`_live_permissions`（V-045）、`_numeric_modifier`：
  权限不是合法字符串时**跳过**，由 V-040 报告，不重复判定（语义分层）；
- `_existing_targets` 另加 `_number_permission()` 为空即返回，避免空串与空串「相等」的误判。

已写入 `CLAUDE.md` 坑 6。
