## 实现说明

- `InheritGuard` 提供 `configure_from_file()`、可注入素材的 `configure()`、`check()`，并提供 `check_inheritance()` / `validate()` 兼容入口。
- 受保护组、段名、规则 ID、错误码和严重度均从 `protected_targets.json`、`validation_rules.csv`、`error_messages.csv` 读取；匹配模式只接受素材登记的 `segment`，按 `.` 路径段精确匹配。
- 每个命中的组独立生成诊断，不在第一条命中后短路；CSV 的警告严重度保持 `result.ok == true`，但诊断不会被静默丢弃。
- 修饰器对象只在显式 `inheritable == false` 时跳过；本卡没有新增作者可见开关，也没有修改 CFG 或目标对象。
- core 文件只依赖 `RefCounted`、`FileAccess`、`JSON` 和 `Diagnostic`，未引用编辑器 API。
