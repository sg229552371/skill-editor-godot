## 10.2 修复一：点语法写「新键」产生 StringName 键（坑 7）

失败用例 `test_metadata_renames_permissions_fields_scopes_sources_and_profiles`：

```
[Failed]: 非法字段描述        ← exposed_fields.gd:240
```

**根因**：`exposure.fields.address = exposure.fields.field_path` 用**点语法给 Dictionary 写新键**，
GDScript 生成的是 **StringName** 键 `&"address"`，不是 String。引擎校验元数据用 `field is String`，
StringName 不是 String → 拒收。诊断脚本打印确认：`fields=[..., &"address"]`。

**判定：测试写法问题，不是引擎缺陷**。素材来自 `JSON.parse_string`，键必为 String；
为迁就测试而放宽引擎校验等于掩盖键类型不一致，故改测试不改引擎。

修复：新键一律改下标语法 —— `fields["address"]`、`modifier["grant"]`、`modifier["references"]`、
`entry["address"]`、`cfg["loadout"]`。已写入 `CLAUDE.md` 坑 7。
