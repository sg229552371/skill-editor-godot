### section / context 接线说明

- HostCast.begin 需要真实 `template_id` 与调用方提供的 `shot_id`。从 `options.roots` 按 template 匹配，为每条实际请求建立宿主，不凭空生成 shot_id。
- 宿主键为 `template_id:root_index`，同模板多个 root 请求不会相互覆盖 state；ctx 包含 template_id、shot_id、tick=0、项目解析后的 tick_rate。
- `_host_requests` 存 cast request 的深拷贝；`_host_contexts` 存各实际请求的 ctx；`_host_states` 存 begin/advance 返回的 state。
- 未被 roots 请求的模板仍 validate，但不 begin，避免创建虚构施放。其它四 section 不注册，即使模板未被 roots 请求，也仍拒绝。
- HostCast 的失败 path 是局部字段（如 `shot_count`），且并不读取 ctx 中的路径前缀。为满足第 4 轮验收第 9 条，runner 将局部 path 补为 `params.templates[i].cast.<原局部path>`；**error 文本和 code 保留原值**，失败字典直接返回，不经过会改写 error 文本的 `_failure`。因此 path 是补全后的路径，而不是原始局部 path 字符串，特此明确。

## 零实体前摇：原句与改写

原 T-050 第 212–213 行：

```gdscript
if _entities.is_empty() or not _family.sync_instances(_derive.snapshot_state(), _facts):
    return _failure("family", _family.last_error)
```

交付第 242–247 行（实际文件使用 tab 缩进）：

```gdscript
var family_synced: bool = _family.sync_instances(_derive.snapshot_state(), _facts)
if _entities.is_empty() and _host_states.is_empty():
    return _failure("family", _family.last_error)
# The ledger rejects an empty source; pending hosts have no members yet.
if not family_synced and not _entities.is_empty():
    return _failure("family", _family.last_error)
```

**为什么不能简单改为 `if not sync: return failure`：** 已读取 `family_ledger.gd:105–110`，该模块会以 `Missing nonempty derivation instance ledger` 拒绝空实例账本。若拆掉 or 后依旧立即拒绝 sync=false，合法前摇仍无法 start。

本轮按已批准的“先无条件 sync，再判既无实体且无宿主才失败”处理：

1. start 无条件执行一次真实 sync，不注入占位实例；
2. 无实体且无宿主，仍失败；
3. 无实体但有宿主，允许等待，不以空源导致的 sync=false 拒绝；
4. 有实体时，sync 必须成功；
5. `_consume_emissions` 在已有实体时再次同步真实账本，保证新根在下一次 contact 前具备 family facts。零实体/空 emissions 时不调用会必然拒绝空源的 sync。

没有修改 family 模块。前摇 start 时 family 内部可能暂留空源错误文本，直到第一个实际根同步成功；runner 成功返回前清空自身 last_error。上述分支是本轮放宽的具体实现，不是“空账本 sync 已成功”的声明。
