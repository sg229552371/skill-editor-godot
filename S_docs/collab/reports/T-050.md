## 公开 API

`PreviewRunner` 为 `RefCounted`，不依赖场景树或编辑器 API。

| API | 契约 |
|---|---|
| `start(cfg: Variant, options: Dictionary) -> Dictionary` | 正式 CFG 同结构输入；先 Codec 结构校验，再共享 CfgSchema、ParamResolver、各 runtime 模块 preflight。成功 `{ok:true, fingerprint, tick_rate, diagnostics:[], error:""}`；失败 `{ok:false, path, error, diagnostics}`。结构诊断保留实际缺失路径。当前场运行中拒绝再次 start。 |
| `advance_ticks(count:int=1) -> Dictionary` | 逐 tick 推进，真实运动、候选、份级结算、事件 FIFO、派生、生命周期；子体在事件 tick+1 开始运动/判定。 |
| `advance_seconds(seconds:float) -> Dictionary` | 只消费显式模拟时长，按注入 tick_rate 向上取整后逐 tick 执行；不是渲染 delta。多次非整数 tick 的秒输入会逐次取整，精确重放应使用 advance_ticks。 |
| `snapshot_state() -> Dictionary` | 返回隔离的 entities/events/records/targets/notices、原始 derive/budget 账本、clock/RNG 状态、CFG 指纹与项目配置指纹。events 与 records、debug 分开。 |
| `presentation_random() -> float` | 只抽取表现 RNG，不暴露逻辑 RNG 句柄。 |
| `stop() -> Dictionary` | 存活实体走 Derive.purge；静默终止，不补 hit/vanish、不产生子体。 |

### options 是宿主运行态输入，不是新的 CFG 分支

必填：

- `seed: int`。
- `roots: Array[{template_id: String, shot_id: String, instance_id?: Variant}]`：显式根出手列表，不猜 templates[0] 是根；同一 shot_id 才是同次出手。instance_id 永不用于分配，只记建议值是否合法及实际分配值。
- `targets: Array[Dictionary]`：宿主已解析的稳定目标列表（允许空）；每项 `target_id/position:Vector2/alive` 以及 `settle_meta.target_roles` 要求的无敌/闪避/免疫表。内部深拷贝；这版不做队伍查询/目标选择，宿主必须提供适用于本场模板的目标列表。
- `handlers: Dictionary[part_type, Callable]`：沿用 T-044 的真实宿主适配接口；缺适配器显式失败，绝不补一个永真 no-op。测试适配器实际扣 HP 并更新 alive，只支持夹具使用的 physical/fire，其它类型调用即失败。
- `template_families: Dictionary[template_id, String]`：显式已解析家族路由。实体家族由根实例命名空间 + 此路由生成；分裂母子绑定相同路由，不从模板名字、时间或技能 ID 猜家族。
- `derivation_bindings: Dictionary`：T-045 已冻结的 template_id → trigger key → `{budgets, reject_visited}` 表。

可选：

- `project_config`：**整份替换**文件配置，不合并默认。未传才读取 `res://data/project_config.json`；显式传空/缺频率不会回落。项目 JSON 整数 float 在边界做有限/整值校验并转 int，之后同时注入 Budget.configure 和 Derive 构造器。
- `motion_inputs: Dictionary[template_id, Dictionary]`：T-042 宿主输入。额外入口 `flight_seconds` 按项目频率转为 flight_ticks，禁止两者双写，并检查转换溢出。CFG 内 speed 仍是每 tick 像素，不除以 tick_rate。

CFG 使用深拷贝；CFG 指纹为 `JSON.stringify(cfg, "", true, true).sha256_text()`（递归排序键、全精度），不会把运行结果写回 CFG。项目配置另算指纹，不把两枚指纹混用成已认证状态；V-084 认证仍归 T-054。
