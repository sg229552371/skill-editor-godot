运行期接线所需注入形状（本卡局部适配结构，**待审核方接线确认，不代表已改写全局素材契约**）：

```gdscript
presentation_meta["event_bindings"] = {
    "fx": {"hit": "on_hit", "hit_settled": "on_settled"},
    # 其它段也登记 Dictionary；允许 {} 表示该段无结果订阅。
    # evaded_all 可显式映射到宿主提供的表现槽位；不自动补槽位。
}
presentation_meta["forbidden_logic_keys"] = [/* 审核方提供的正式清单 */]
```

- `event_bindings`：段名 → 合法逻辑事件 → 段内直接子键；子键不存在/空时没有 cue；槽位字符串为空表示选择整个非空段（例如 camera）。
- `required_sections`：沿用现有素材，bindings 要提供各段 Dictionary；空段保留未绑定语义。
- 每个结果 cue 形如 `{section, event, binding}`；数组槽位作为一个整体保留在 binding，不展开成多条资源 cue。返回顶层只有 `{ok, error, cues}`。
- 映射遍历跳过 `_` 注释键；不会把注释当第八个段或事件。所有七段只做通用选择，不硬编码段名到事件映射。
- `alignments()` 返回深副本；规范化也只作用于内部 bindings 副本，不改调用方 CFG。
