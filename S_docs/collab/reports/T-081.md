## 实现要点（对照硬门禁）

1. **校验在落盘之前**：`CfgCodec.validate_structure` → `CfgSchema.validate` → `encode` → 写文件。
   任一步失败即返回，**不打开目标文件**，因此不可能截断既有文件（用例 `test_rejected_save_preserves_existing_file` 有原文比对）。
2. **转发目标已存在且有测试**：`CfgCodec`（`test_schema_codec` 15 例）与 `CfgSchema`（`test_schema_structure`）。
   未改两者任何签名与语义。
3. **不新增 API 面**：改动只在 `skill_api.gd` 内，未新建 `api/` 文件。
4. **语义校验仍在上游**：`save_cfg` 无 context 入参，无法跑 V-001…084 的 context 依赖项；
   因此返回 `validation_scope:"structure+schema"` + `requires_semantic_validation:true`，
   **明确告知调用方**语义校验必须由 `validate_with_context` 先行完成（T-025 `save_flow` 路径）。
   这不是静默降级：字段显式暴露，且 `test_smoke` 的桩断言仍成立。
