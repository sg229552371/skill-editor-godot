## 依赖与接口版本

- 冻结接口：`res://skill_core/api/diagnostic.gd`（Diagnostic 的七字段及 `to_dict()`，只读）。输入兼容 Diagnostic 对象和七字段 Dictionary；不调用 `Diagnostic.make()`，不依赖文案文件解析。
- 注入素材：`res://data/diagnostic_meta.json` 的 `severity_order`、`field_order`、`dedupe_keys`；调用方用 `DiagnosticSorter.load_metadata()` 获取经 static 缓存的 JSON 元数据，再 `configure(metadata)` 注入；无隐式运行期 CSV/Markdown/YAML 解析。注入失败时 `sort_diagnostics()` 显式返回失败。
- 返回接口：`sort_diagnostics(Array) -> Dictionary`，字段为 `ok`、`diagnostics`、`removed`、`duplicates`、`error`。失败时 diagnostics/duplicates 为空、removed=0、error 非空；空输入但已合法配置时 ok=true。
- 去重口径：排序前以素材指定的五元组完全相等为重复，保留首次出现的原对象；`removed` 是移除数量，`duplicates` 按输入顺序保存被移除对象。输入及返回的数组互相独立，但诊断元素**浅拷贝引用**、不复制对象/字典。若完全相同排序键而不同诊断，则保持输入相对顺序（素材 `_tie_breaker_note`）。
