### RunDiff 的宿主配置（不是 CFG 字段）

```gdscript
var diff = RunDiff.new()
diff.configure({
    "limits": {"max_trace_ticks": host_limit},
    "runner_options": runtime_options, # 原样透传真实 runner options 的深副本
    "runner_factory": func(): return RunnerScript.new(), # 真实 runner 推荐全新实例
    # 可选："trace_fields": ["entities", "events", "records", "targets", "clock.logic_rng"],
    # 可选："post_tick_hook": hook, # hook(index:int, detached_sample:Dictionary, runner:Variant)
})
var result = diff.diff_runs(RunnerScript.new(), cfg, 10)
```

- `limits.max_trace_ticks` 无回落数字：未提供、非有限、非正或非整数均显式失败；支持 JSON 注入的整数 float。
- `capture` 要求 runner 已 start 且处于 tick 0，首样本是当前 tick 0；N 个样本只推进 N−1 次。时钟不按一步一 tick 推进时显式失败，不把采样下标伪造为实际时钟。
- `runner_options` 对 capture 非必填；diff_runs 必须配置其中的显式 `seed:int`。本模块没有凭空猜测或读取 runner 私有配置。
- `trace_fields` 是非空字典路径白名单（支持 `clock.logic_rng` 这样的点路径，不支持数组下标 / 通配符）；遗漏登记字段时报错，不静默生成空投影。
- 默认捕获完整快照，仅排除 `clock.presentation_rng`；保留 `clock.logic_rng`、实体、事件、记录、目标、预算、身份等逻辑信息。Vector2/Vector3/Color 拆为可定位分量；数值使用 `JSON.stringify` 字符串，保留唯一例外 `tick:int`。
- hook 在脱离 runner 的序列化快照副本上执行；再深复制并规范化写入 trace。tick 是保留字段，hook 不准更改；hook 可显式调用 runner.presentation_random，但属于可信宿主回调，不是沙箱。
- diff_runs 给每次 start 独立 cfg/options 深副本；结束或捕获失败后 stop。返回 compare 冻结字段，另附两边 trace、requested/captured_ticks、truncated。
