## 最终公开 API

```gdscript
class_name FieldQuery
extends RefCounted

var last_error: String = ""
func configure(catalog_entry: Dictionary, policy: Variant = null) -> Dictionary
func query(path: String) -> Dictionary
func query_all() -> Array
```

- configure 返回 `{ok, error}`；必须提供 author_params（Array 或 Dictionary）、locked_params（Dictionary）、relic_params（Dictionary）、default_cfg（Dictionary）。失败清空旧声明并保持不可查询状态。
- query 每次返回新 Dictionary，固定九键：ok / error / path / locked / lock_reason / open / source / writable。错误时 source=unknown，open / locked / writable 全 false，error 和 last_error 均非空。
- query_all 每次生成新 Array 与新记录；未配置返回 [] 并记录 last_error。
- 内部只保留新建的路径、段归属、理由记录（字符串），不保留入参 catalog/policy 或 default_cfg 内的可变值引用。
- 不输出诊断、不判严重度、不解析覆盖或修饰器、不保存任何 CFG。

### 判定素材字段与来源口径

| 输入字段 | 用法 |
|---|---|
| author_params 数组元素 / Dictionary 的键 | 作者开放声明；Dictionary 的语义说明值不作为权限 |
| locked_params 的键 | 锁定声明；对已知子字段向下收紧，含数组子字段 |
| locked_params 的 String 值 | 原样返回 lock_reason；空白/null/数组/数值均拒绝配置，绝不造理由 |
| relic_params 的键 | 登记可查询但非作者开放的路径，source=relic_params；三档授权值不转换为作者锁定 |
| default_cfg 的树结构 | 深度优先按声明顺序收集叶路径，含数字数组下标、空数组、空对象、null；不保留或返回值 |
| policy | 仅接受 null / Dictionary；不保留引用，不用物品权限推导作者权限，理由见缺列清单 |

同一路径归属优先级：**locked > author_params > relic_params > default_cfg**。lock 命中时 open=false；writable 始终等于 open and not locked。author / locked 的父节点声明可约束已登记后代，但不凭父节点声明发明未登记字段。默认存在且作者已开放时 source=author_params，不因有默认值而遮盖开放声明。

**source 是当前卡片的声明归属，不是最终值的运行时 provenance。** 未提供修饰器来源事实时不生成 modifier。需要精确默认值/覆盖/最终值来源链时仍使用 ParamResolver 的 sources/source_table。

### 路径与 query_all 顺序

- 逻辑路径支持 `params.x` 与 `x` 别名；只移除一个前导 `params.`，不做任意后缀匹配。
- 素材声明可写 `templates[i].parts[i].factor`，不接受素材声明硬填数字下标。
- 查询可用 `[i]` 模板或非负数字下标；模板只有匹配的声明存在才已知，具体默认索引不自动通配。
- default_cfg 的**键**只能是无点号、无方括号、无空白的单段；数组数字下标只由遍历产生。
- 可查询素材树的 `arrays[0].path`、`arrays[1].path`；此处查询的是输入 default_cfg 树实际登记的地址，不读取另一份全局元数据，也不把这些地址当作者手填键。
- 支持单卡上下文的 `bricks[n].author_params.*` / locked_params / relic_params / default_cfg 四种显式展示地址。n 只作为展示地址剥离，不承担整份 CFG 的卡片寻址或索引有效性校验。
- query_all 顺序为 catalog_entry 中相关段的实际插入顺序，段内按原声明顺序，default_cfg 按深度优先原键序。规范化别名去重，保留首次声明拼写。只列显式声明或默认叶/空容器，不生成未出现的实例索引。
