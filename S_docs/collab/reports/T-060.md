## 公开 API

- `configure(metadata, cfg) -> Dictionary`：加载/校验表现元数据，深拷贝 CFG 的 `presentation` 草稿并渲染。
- `render(metadata, cfg) -> Dictionary`、`set_context(metadata, cfg) -> Dictionary`：`configure` 的别名。
- `get_value() -> Dictionary`：返回与面板内部完全隔离的表现草稿副本。
- `get_sections() -> Array[String]`、`get_section_names() -> Array[String]`：返回素材登记槽位。
- `get_section_fields(section)`：返回素材登记的字段顺序/集合。
- `get_control(section, field) -> Control`：按素材字段寻址控件。
- `get_status(section) -> String`、`get_error() -> String`：读取槽位状态与显式错误。
- `set_value(section, field, value) -> bool`：验证并修改面板 draft；非法值拒绝并点名完整 `presentation.<section>.<field>` 路径。
- 信号 `value_changed(value)`：面板 draft 改变时发出隔离副本。

- `configure` 遍历 `metadata.required_sections`，不以具体段名作控制流判断。
- 每槽字段直接读取 `metadata.section_field_index[section]`。
- 控件类型、枚举和值校验通过 `leaves` / `arrays` / `objects` 中匹配完整路径取得；没有隐藏默认值填充逻辑。
- `carrier` 只由对应叶登记的 `enum` 生成 OptionButton。

## 空段「未绑定」证据

- `_presentation` 只深拷贝输入中实际存在的 `presentation`；缺失槽位显式放入空字典。
- `_add_field` 仅在 `section_value.has(field)` 时读取输入值，否则控件为空并显示 `placeholder_text = "未绑定"`。
- `_update_status` 对空字典显示 `未绑定`。
- 叶登记中的 `default` 只用于校验元数据来源，不会在面板初始化时应用。

## 审核方复核结论（WorkBuddy，2026-10-18 23:46 · 一轮 → **PASS（审核方修 1 处实现）**）

**首轮门禁**：7 用例 230 asserts，**2 条红**：`carrier.item_count` 取到 null（`as OptionButton` 失败）。

**真因**：`_make_control()` 里 `OptionButton` 的 `connect` 与 `return` **嵌在 `if value is String:` 里面**——
初值未绑定（`{}`）时 `value` 是 null，于是落到末尾的 `LineEdit` 分支。结果：枚举字段在"空段/未绑定"场景下
**变成自由文本输入框**，既没有下拉、也绕过了取值校验。**这不是测试写错，是实现的缺陷**（空段恰恰是本卡的核心场景）。

**审核方修复**：把 `connect` + `return option` 提到 `if` 外，让枚举叶子**无条件**返回 `OptionButton`；
初值命中时才 `select()`。修后 **7/7 PASS，239 asserts**。

**验收复核**：七槽来自素材（换 material 后槽与叶子随变）、空段回传 `{}` 而不是被填默认值、
`carrier` 选项逐项等于素材 enum、非法值被拒且错误**点名** `presentation.trail.carrier`、
入参 CFG 与回读值双向脱离 —— 均有对应用例，且断言是逐项比对不是"非空即可"。

**记档**：本卡只写 `presentation_panel.gd`，**未接 `plugin.gd`**（宿主接线由审核方统一做）。
